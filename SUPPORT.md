# Support

Use GitHub Issues for reproducible application/backend/frontend defects, deployment problems, documentation gaps, security-adjacent behaviour and bounded feature proposals. Include the affected version/revision, expected and observed behaviour, and the smallest useful reproduction/evidence reference.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not be disclosed publicly before remediation.

This repository owns KiranaOS implementation and product behaviour. External protocols, identity/trust infrastructure and deployment authorities retain their own normative and operational authority.
